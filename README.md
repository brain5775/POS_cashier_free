# Integrated Cashier POS + Inventory Management System

Python desktop application built with CustomTkinter. CSV files are the only persistent business-data store.

## Run

```bash
python main.py
```

Default first administrator:

- Username: `admin`
- Password: `ChangeMe123!`

Change this password immediately in a real deployment.

## Data

CSV files are stored under `data/` by default. Backups are stored under `backups/`.

## Tests

```bash
python -m pytest
```
